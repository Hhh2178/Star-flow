# Governance

## Purpose

This folder owns durable operating rules for Stars Flow. It explains how project facts are recorded, how branches are used, how secrets are handled, and how changes are verified.

## Files

- `root-entry-responsibility-matrix.md`: what root files own.
- `documentation-governance-standard.md`: one-fact-one-source and doc lifecycle.
- `engineering-guardrails.md`: safety, verification, dependency, and deployment boundaries.
- `worktree-and-branch-policy.md`: `main/dev` branch policy and short-lived feature branches.
- `secrets-and-access-policy.md`: SSH key, env, Provider key, and server access rules.

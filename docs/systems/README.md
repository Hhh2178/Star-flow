# Systems

## Purpose

This folder maps Stars Flow systems and their contracts. Each system doc should describe purpose, runtime shape, interfaces, data model, permissions, failure modes, and verification.

## Current Systems

- `harness/`: outer repository operating layer and verification scripts.
- `app/`: Toonflow fork submodule and runtime.
- `frontend/`: user-facing production workspace visual standards.
- `admin/`: internal admin console visual standards.
- `providers/`: Provider and model configuration boundary.
- `ops/`: server deployment, staging, and observability boundary.

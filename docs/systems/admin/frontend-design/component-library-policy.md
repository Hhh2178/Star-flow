# Admin Component Library Policy

## Current Policy

Use Toonflow's existing UI approach first. Do not introduce a new component library until the current app structure is understood.

## Allowed Changes

- Extract repeated admin controls into shared components.
- Add consistent status pills, table actions, drawers, and form rows.
- Keep layout dense and operational.

## Not Allowed Without Approval

- Replacing the full UI library.
- Rewriting the app shell before the server/team workflow is stable.
- Adding decorative components that do not support production workflows.

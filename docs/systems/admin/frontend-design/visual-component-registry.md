# Admin Visual Component Registry

| Component | Purpose | Reuse Rule |
| --- | --- | --- |
| Admin shell | Holds sidebar and page content | One shell for admin routes |
| Data table | Lists users, providers, models, tasks, costs | Use compact row tokens |
| Filter bar | Search and filter operational lists | Keep actions left-to-right |
| Detail drawer | Edit or inspect selected record | Reuse for Provider/model/task details |
| Status pill | Shows enabled, disabled, failed, pending | Use token severity mapping |
